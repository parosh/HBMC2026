\section{Regular Model Checking}
\label{sec:rmc}
% ═════════════════════════════════════════════════════════════════════════════

In this section, we consider parameterized systems with a linear topology in
which the processes are finite-state and a process may communicate with its
immediate neighbors. Linear topologies are common in parameterized systems,
where the position of a process may, for instance, reflect its priority
compared to the other processes. Already for this class of systems, all
non-trivial verification problems are undecidable. We present the framework
of \emph{regular model checking}~\cite{KMMPS97,KW01,BW98,BJNT00}, which uses
regular languages as a uniform representation of sets of configurations, and
we describe in detail one technique within the framework, namely
\emph{acceleration} based on quotienting~\cite{AJNO02,AJNO03}.

\subsection{Near-Neighbor Communication}

We consider systems that consist of an arbitrary number of finite-state
processes organized in a linear array. In a \emph{near-neighbor}
communication, a process communicates with its left or right neighbor, and the
two processes change their states simultaneously. As an example, we use a
simple \emph{token-passing protocol}. Initially, the leftmost process owns the
token. In each step, the process that has the token passes it to its right
neighbor. The safety property states that at most one process has the token
at any point during the execution of the system.

Near-neighbor communication leads to undecidability of safety properties. The
proof is a reduction from the halting problem for Turing machines, in a
similar manner to the proof for rings~\cite{Suz88}. Given a Turing
machine~$\mathcal{M}$, the instance of size~$n$ of the system simulates the
computations of~$\mathcal{M}$ that use at most $n$ tape cells. Each cell is
represented by one process, whose local state encodes the symbol stored in the
cell, together with a flag that indicates whether the head of~$\mathcal{M}$
points to the cell. If the flag is set, the local state also stores the
control state of~$\mathcal{M}$. Near-neighbor communication is then used to
move the head, to change the symbol in the current cell, and to change the
control state. A bad configuration is reachable for some~$n$ if and only if
$\mathcal{M}$ halts.

\subsection{Words, Relations, and Transducers}

In regular model checking, the behavior of a system is described in three
steps. First, we fix a finite alphabet in which each symbol represents the
local state of a process. Second, a configuration is represented by a word,
where each position describes the state of one process, and sets of
configurations are represented by finite automata or regular expressions.
Third, the transition relation is represented by a finite automaton that reads
pairs of symbols, a so-called \emph{finite-state transducer}. The framework
makes it possible to use the well-developed algorithms for manipulating
regular languages, which have been implemented, for example, in the Mona
tool~\cite{Mona95}.

Let $\Sigma$ be a finite alphabet. We consider \emph{length-preserving}
relations on words, that is, relations $R \subseteq \Sigma^* \times \Sigma^*$
such that $u$ and $v$ have the same length whenever $(u,v) \in R$. For a set
$L \subseteq \Sigma^*$ of words, we write $L \circ R$ for the set of words~$v$
such that $(u,v) \in R$ for some $u \in L$. For two relations $R_1$ and
$R_2$, we write $R_1 \circ R_2$ for their composition, which contains the
pairs $(u,w)$ such that $(u,v) \in R_1$ and $(v,w) \in R_2$ for some word~$v$.
We define $R^0$ to be the identity relation and $R^{i+1} = R^i \circ R$. The
transitive closure of~$R$ is the union $R^+$ of all $R^i$ with $i \geq 1$, and
the reflexive transitive closure is $R^* = R^0 \cup R^+$.

A \emph{transducer} over~$\Sigma$ is a tuple $T = (P, q_0, \Theta, F)$, where
$P$ is a finite set of states, $q_0 \in P$ is the initial state, $\Theta
\subseteq P \times (\Sigma \times \Sigma) \times P$ is the transition
relation, and $F \subseteq P$ is the set of accepting states. We write $q
\xrightarrow{(a,b)} r$ if $(q,(a,b),r) \in \Theta$. A transducer is a finite
automaton over the alphabet $\Sigma \times \Sigma$, so it accepts words of
pairs $(a_1,b_1)(a_2,b_2) \cdots (a_n,b_n)$. We say that $T$ \emph{accepts}
the pair of words $(a_1 \cdots a_n, b_1 \cdots b_n)$ if it accepts the word
$(a_1,b_1) \cdots (a_n,b_n)$, and we write $R(T)$ for the length-preserving
relation that consists of all pairs accepted by~$T$. In regular model
checking, $R(T)$ is the transition relation of the system. For simplicity, we
write $R^i(T)$, $R^+(T)$, and $R^*(T)$ for $(R(T))^i$, $(R(T))^+$, and
$(R(T))^*$. A pair $(u,v)$ belongs to $R^i(T)$ if $u$ can be rewritten
into~$v$ by $i$ successive runs of~$T$.

\paragraph{The token-passing protocol.}
For the token-passing protocol, the alphabet is $\Sigma = \{\Tok, \NoTok\}$,
where $\Tok$ means that the process has the token and $\NoTok$ means that it
does not. For instance, the word $\NoTok\NoTok\Tok\NoTok\NoTok$ represents a
configuration with five processes in which the third process has the token.
The set of initial configurations is given by the regular expression
$\Tok\NoTok^*$ (Figure~\ref{fig:transducer}(a)): the leftmost process has the
token, and it is followed by an arbitrary number of processes without the
token. The transition relation is given by the transducer~$T$ of
Figure~\ref{fig:transducer}(b). The transducer copies a prefix of processes
without the token in state~$q_L$, reads the pair $(\Tok,\NoTok)$ for the
process that gives the token away and the pair $(\NoTok,\Tok)$ for its right
neighbor, and copies the remaining processes in state~$q_R$. For instance,
$T$ accepts the word $(\NoTok,\NoTok)(\NoTok,\NoTok)(\Tok,\NoTok)
(\NoTok,\Tok)(\NoTok,\NoTok)$, which represents the pair
$(\NoTok\NoTok\Tok\NoTok\NoTok, \NoTok\NoTok\NoTok\Tok\NoTok)$, in which the
token is passed from the third to the fourth process.

\paragraph{Safety.}
Let $\Init$ be the regular set of initial configurations and $\Bad$ the regular
set of bad configurations. A safety property is verified by checking that no
bad configuration is reachable, that is, that
\[
(\Init \circ R^*(T)) \cap \Bad = \emptyset .
\]
For the token-passing protocol, the bad configurations are those in which at
least two processes have the token, given by the regular expression $(\Tok +
\NoTok)^* \Tok (\Tok + \NoTok)^* \Tok (\Tok + \NoTok)^*$. Since $R^*(T) = R^0
\cup R^+(T)$, it suffices to compute a transducer $T^+$ with $R(T^+) =
R^+(T)$. The reachable set $\Init \circ R^*(T)$ is then regular and can be
computed with standard automata constructions, and the intersection with
$\Bad$ can be checked for emptiness. The transitive closure is also the key
to verifying liveness properties, where it is used to detect cycles in the
transition relation~\cite{AJNOS04}.

\subsection{Acceleration}
\label{sec:acceleration}

In general, the transitive closure $R^+(T)$ is not computable, and it may not
even be regular. Our goal is a technique that computes a finite-state
transducer for $R^+(T)$ in the cases where such a transducer exists. A first
attempt is to compute, for $n = 1, 2, 3, \ldots$, a transducer $T^n$ with
$R(T^n) = R^n(T)$. For the token-passing protocol, $T^3$ passes the token
three positions to the right (Figure~\ref{fig:closures}(a)), and the
transducer for $R^+(T)$ passes the token an arbitrary positive number of
positions (Figure~\ref{fig:closures}(b)). Computing the approximations $T^n$
one by one does not converge, since $T^n$ needs $n+2$ states. Instead, we
\emph{accelerate} the computation in two steps. First, we define an
infinite-state transducer, the \emph{column transducer}, that accepts
$R^+(T)$. We never build the column transducer explicitly. Second, we define
an equivalence relation on its states and construct the quotient with respect
to this relation incrementally. If the construction terminates, the result is
a finite-state transducer for $R^+(T)$.

\paragraph{The column transducer.}
The column transducer simulates a sequence of $i$ runs of~$T$ by a single
run. Figure~\ref{fig:columns} shows four runs $\rho_1, \ldots, \rho_4$ of the
transducer~$T$ on words of length five. The runs relate the pairs
$(\Tok\NoTok\NoTok\NoTok\NoTok, \NoTok\Tok\NoTok\NoTok\NoTok)$,
$(\NoTok\Tok\NoTok\NoTok\NoTok, \NoTok\NoTok\Tok\NoTok\NoTok)$,
$(\NoTok\NoTok\Tok\NoTok\NoTok, \NoTok\NoTok\NoTok\Tok\NoTok)$, and
$(\NoTok\NoTok\NoTok\Tok\NoTok, \NoTok\NoTok\NoTok\NoTok\Tok)$, so the pair
$(\Tok\NoTok\NoTok\NoTok\NoTok, \NoTok\NoTok\NoTok\NoTok\Tok)$ belongs to
$R^4(T)$. If we read the four runs column by column, we obtain a single run
whose states, called \emph{columns}, are sequences of four states of~$T$. Each
step of this run is labeled by the total effect of the corresponding steps of
the four runs. For instance, the first step is labeled $(\Tok,\NoTok)$, since
the first steps of the four runs rewrite $\Tok$ to $\NoTok$, and then $\NoTok$
to $\NoTok$ three times. The second step is labeled $(\NoTok,\NoTok)$, since
the second steps rewrite $\NoTok$ to $\Tok$, then $\Tok$ to $\NoTok$, and then
$\NoTok$ to $\NoTok$ twice.

Formally, from a transducer $T = (P, q_0, \Theta, F)$ we define the
\emph{column transducer} $T^{\mathit{col}}$ as follows. Its states are the
nonempty sequences of states of~$T$, that is, the set~$P^+$. Its initial
states are the sequences $q_0^i$ with $i \geq 1$, and its accepting states are
the nonempty sequences of accepting states of~$T$. For columns $c = q_1 \cdots
q_m$ and $c' = r_1 \cdots r_m$ of the same length, there is a transition $c
\xrightarrow{(a,a')} c'$ if there are symbols $a_0, a_1, \ldots, a_m$ with
$a_0 = a$ and $a_m = a'$ such that $q_j \xrightarrow{(a_{j-1},a_j)} r_j$ is a
transition of~$T$ for each $j$ with $1 \leq j \leq m$. A run of the column
transducer from $q_0^i$ to a sequence in $F^i$ accepts exactly the pairs
in~$R^i(T)$, so $T^{\mathit{col}}$ accepts the relation~$R^+(T)$. Its set of
states is infinite, however, so it cannot be built explicitly.


\paragraph{Quotienting.}
We now define an equivalence relation on columns that identifies columns
which differ only in the number of repetitions of certain states. We say that
a state~$q$ of~$T$ is \emph{left-copying} if every run of~$T$ from the
initial state to~$q$ reads only pairs of the form $(a,a)$. Symmetrically, $q$
is \emph{right-copying} if every run from~$q$ to an accepting state reads only
pairs of the form $(a,a)$. In other words, the prefix read before a
left-copying state and the suffix read after a right-copying state are copied
unchanged. In Figure~\ref{fig:transducer}(b), the state~$q_L$ is left-copying
and the state~$q_R$ is right-copying. We say that two columns are
\emph{equivalent} if they become equal when every block of consecutive
repetitions of a left-copying or right-copying state is replaced by a single
occurrence of that state. For instance, the columns $q_R q_R q\, q_L$ and $q_R
q\, q_L q_L$ are equivalent. Each equivalence class is described by a regular
expression $e_1 e_2 \cdots e_k$, where each $e_j$ is either $q^+$ for a
left-copying or right-copying state~$q$, or a single state that is neither
left-copying nor right-copying, and where two consecutive $e_j$ are equal only
if they are single states. We write $[c]$ for the equivalence class of a
column~$c$.

The \emph{quotient transducer} has the equivalence classes as states. Its
initial state is $[q_0] = q_0^+$, assuming that $q_0$ is left-copying, and its
accepting states are the classes of accepting columns. There is a transition
$[c] \xrightarrow{(a,a')} [c']$ whenever $c \xrightarrow{(a,a')} c'$ is a
transition of the column transducer. With this choice of equivalence, the
quotient accepts the same relation as the column transducer~\cite{AJNO02},
namely~$R^+(T)$. The quotient may still be infinite, since $R^+(T)$ need not be
regular, but in many practical cases it is finite.

\paragraph{The procedure.}
The quotient is built incrementally by Procedure~\ref{alg:acceleration}, which
explores the classes reachable from the initial class. To compute the
successors of a class, we use two operations. For a state~$q$, we write
$q^\oplus$ for $q^+$ if $q$ is left-copying or right-copying, and for~$q$
otherwise. For two classes, we write $[c] \odot [c'] = [c \cdot c']$ for the
class of the concatenated column; on regular expressions, $(e_1 \cdots e_k)
\odot (f_1 \cdots f_l)$ is $e_1 \cdots e_k f_1 \cdots f_l$, except when $e_k$
and $f_1$ are both equal to $q^+$ for some copying state~$q$, in which case it
is $e_1 \cdots e_k f_2 \cdots f_l$. We write $C \Rightarrow_{(a,a')} D$ for
classes $C$ and~$D$ if either
\begin{itemize}[leftmargin=*,nosep]
\item $q \xrightarrow{(a,a')} r$ is a transition of~$T$, with $C = q^\oplus$
and $D = r^\oplus$, or
\item $C = C_1 \odot C_2$ and $D = D_1 \odot D_2$, and there is a symbol~$b$
with $C_1 \Rightarrow_{(a,b)} D_1$ and $C_2 \Rightarrow_{(b,a')} D_2$.
\end{itemize}
The second case composes the effect of the upper part of a column with that of
its lower part, as in Figure~\ref{fig:columns}.

\begin{algorithm}[t]
\caption{Acceleration by quotienting}
\label{alg:acceleration}
\begin{algorithmic}[1]
\REQUIRE A transducer $T = (P, q_0, \Theta, F)$
\ENSURE A transducer $(S, q_0^+, \Theta', F')$ for $R^+(T)$, if the procedure terminates
\STATE $S \leftarrow \emptyset$; $\Theta' \leftarrow \emptyset$; $F' \leftarrow \emptyset$; $W \leftarrow \{q_0^+\}$
\WHILE{$W \neq \emptyset$}
  \STATE pick and remove a class $C$ from $W$
  \IF{$C \notin S$}
    \STATE $S \leftarrow S \cup \{C\}$
    \FORALL{$a$, $a'$, $D$ with $C \Rightarrow_{(a,a')} D$}
      \STATE $W \leftarrow W \cup \{D\}$
      \STATE $\Theta' \leftarrow \Theta' \cup \{(C, (a,a'), D)\}$
      \IF{$D$ consists of accepting columns}
        \STATE $F' \leftarrow F' \cup \{D\}$
      \ENDIF
    \ENDFOR
  \ENDIF
\ENDWHILE
\end{algorithmic}
\end{algorithm}

The procedure maintains a set~$W$ of classes that have been found to be
reachable but whose successors have not yet been computed. It starts from the
initial class $q_0^+$. In each iteration, it removes a class from~$W$ and, if
the class has not been explored before, adds its outgoing transitions and its
successors. The relation accepted by the partial result grows with each
iteration and is always contained in~$R^+(T)$. The procedure terminates when
$W$ is empty, which happens exactly when the reachable part of the quotient is
finite.

\paragraph{The token-passing protocol.}
Figure~\ref{fig:quotient} shows the result of the procedure on the transducer
of Figure~\ref{fig:transducer}(b). The procedure starts with the class
$q_L^+$. Since $q_L \xrightarrow{(\Tok,\NoTok)} q$ and $q_L
\xrightarrow{(\NoTok,\NoTok)} q_L$, we obtain the transition $q_L^+
\Rightarrow_{(\Tok,\NoTok)} q$, and, by composing the two, the transition
$q_L^+ = q_L^+ \odot q_L^+ \Rightarrow_{(\Tok,\NoTok)} q \odot q_L^+ =
q\,q_L^+$. The loop on $q_L^+$ comes from the loop on~$q_L$. From~$q$, the
transition $q \xrightarrow{(\NoTok,\Tok)} q_R$ gives the accepting class
$q_R^+$, which has a loop labeled $(\NoTok,\NoTok)$. From the class
$q\,q_L^+$, the upper part writes the token, since $q \Rightarrow_{(\NoTok,\Tok)}
q_R^+$, and the lower part reads it, since $q_L^+ \Rightarrow_{(\Tok,\NoTok)}
q$ and $q_L^+ \Rightarrow_{(\Tok,\NoTok)} q\,q_L^+$. Composing them gives the
transitions from $q\,q_L^+$ to $q_R^+ q$ and to $q_R^+ q\,q_L^+$, both labeled
$(\NoTok,\NoTok)$. From $q_R^+ q$, the lower state~$q$ writes the token, which
gives the transition to $q_R^+$ labeled $(\NoTok,\Tok)$. Finally, the class
$q_R^+ q\, q_L^+$ has a loop and a transition to $q_R^+ q$, both labeled
$(\NoTok,\NoTok)$. At this point, no new classes are produced and the
procedure terminates. The result accepts exactly the pairs in which the token
is moved one or more positions to the right, and it is equivalent to the
transducer of Figure~\ref{fig:closures}(b). Composing it with the initial
configurations gives the reachable set $\NoTok^*\Tok\NoTok^*$, which does not
intersect the bad configurations, so the protocol is safe.

Acceleration is one of several techniques for computing transitive closures or
reachable sets in regular model checking. Related constructions iterate
transducers by identifying equivalent states with bisimulation-like
relations~\cite{DLS01}, and the quotienting technique above has been made
more efficient using simulations~\cite{AJNO03}. \emph{Widening} and
\emph{extrapolation} techniques compute a few iterates, detect a regular
pattern of growth, and extrapolate it to a candidate for the limit, which is
then checked~\cite{Tou01,BLW03,BT02}. \emph{Abstract regular model
checking}~\cite{BHV04} gives up exactness: it alternates between applying the
transducer and abstracting the resulting automata, for example by merging
states that accept the same words up to a given length, and refines the
abstraction when a spurious counterexample is found. For safety verification,
it is enough to find a regular set that contains the initial configurations,
is closed under the transducer, and is disjoint from the bad configurations.
Such a \emph{regular inductive invariant} can be found with automata
learning, in which a learner proposes candidate automata and a teacher
checks the three conditions~\cite{HV05,NJ13,CHLR17}.

The framework extends beyond linear words. Tree automata and tree transducers
represent configurations of systems with a tree topology or with recursive
structure~\cite{AJMO02,BT02}. Liveness properties can be handled by working
with infinite words~\cite{BLW04,BLW05} or through the transitive closure as
mentioned above~\cite{AJNOS04}, and regular proofs of liveness have been
studied for randomized parameterized systems~\cite{LR16}. Surveys of the area
can be found in~\cite{AJNS04,Abd12,Abd21}. In the next section, we present a
technique that replaces regular sets by upward-closed sets, trading generality
for efficiency and guaranteed termination.

\section{Parameterized Systems}
\label{sec:prelim}
% ═════════════════════════════════════════════════════════════════════════════

In this section, we define parameterized systems with a linear topology and the
parameterized reachability problem. Other topologies and communication
primitives are introduced in the sections where they are used.

\subsection{Model}

For a finite set~$A$, we write $A^*$ for the set of finite words over~$A$ and
$A^+$ for the set of nonempty words. For a word~$c$, we write $|c|$ for its
length and $c[i]$ for its $i$th letter, for $1 \leq i \leq |c|$.

A \emph{parameterized system} is a pair $\mathcal{P} = (Q, \Delta)$, where $Q$
is a finite set of \emph{local states} and $\Delta$ is a finite set of
\emph{transition rules}. A rule is either local or global. A \emph{local} rule
has the form $s \to d$, where $s, d \in Q$. A \emph{global} rule has the form
\[
\textbf{if}\ \mathsf{Q}\, j \sim i : S\ \textbf{then}\ s \to d ,
\]
where $\mathsf{Q} \in \{\forall, \exists\}$ is the \emph{quantifier}, ${\sim}
\in \{<, >, \neq\}$ is the \emph{range}, and $S \subseteq Q$. We call $s$ the
\emph{source} and $d$ the \emph{destination} of the rule. A rule with
quantifier~$\forall$ is \emph{universal}, and a rule with quantifier~$\exists$
is \emph{existential}.

A \emph{configuration} of~$\mathcal{P}$ is a word $c \in Q^+$, where $c[i]$ is
the local state of process~$i$. The number $|c|$ of processes is arbitrary but
does not change during a run, that is, processes are neither created nor
removed. Let $c$ be a configuration, $\delta$ a rule with
source~$s$ and destination~$d$, and $i$ a position with $c[i] = s$. We write
$\delta(c,i)$ for the configuration~$c'$ with $c'[i] = d$ and $c'[j] = c[j]$
for all $j \neq i$, provided that one of the following conditions holds:
\begin{itemize}[nosep]
\item $\delta$ is local;
\item $\delta$ is universal, and $c[j] \in S$ for all positions $j \sim i$;
\item $\delta$ is existential, and $c[j] \in S$ for some position $j \sim i$.
\end{itemize}
Otherwise, $\delta(c,i)$ is undefined. We call process~$i$ the \emph{active}
process, and the processes $j$ with $j < i$ and $j > i$ its \emph{left} and
\emph{right context}. We write $c \to c'$ if $c' = \delta(c,i)$ for some rule
$\delta \in \Delta$ and position~$i$, and $\to^*$ for the reflexive transitive
closure of~$\to$. For a set~$X$ of configurations, we write $\Post(X)$ for the
set of configurations $c'$ with $c \to c'$ for some $c \in X$, $\Pre(X)$ for
the set of configurations $c$ with $c \to c'$ for some $c' \in X$, and
$\Pre^*(X)$ for the set of configurations $c$ with $c \to^* c'$ for some $c' \in
X$.

\subsection{The Reachability Problem}

An instance of the \emph{parameterized reachability problem} is given by a
parameterized system~$\mathcal{P}$, a set $\Init \subseteq Q^+$ of
\emph{initial} configurations, and a set $\Bad \subseteq Q^+$ of \emph{bad}
configurations. A configuration~$c$ is \emph{reachable} if $c_0 \to^* c$ for
some $c_0 \in \Init$. We write $\mathcal{R}$ for the set of reachable
configurations. The system is \emph{safe} if $\mathcal{R} \cap \Bad =
\emptyset$. Typically, $\Init$ is a regular set, such as the set of
configurations in which all processes are in a given initial state, and
$\Bad$ is described by a finite set of patterns, such as the configurations in
which two processes are in their critical sections.

The problem is undecidable, although each process has only finitely many
states. Apt and
Kozen~\cite{AK86} showed that verifying a specification for all sizes is not
even semi-decidable, and Suzuki~\cite{Suz88} showed that the problem remains
undecidable for unidirectional rings of identical finite-state processes. In
Section~\ref{sec:rmc}, we sketch a reduction from the halting problem for
Turing machines to the reachability problem for linear systems in which
neighboring processes communicate.
